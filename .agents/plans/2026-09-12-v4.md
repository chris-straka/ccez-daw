## Goal

Close the DAW-to-game loop for a Godot developer: a GDScript playback-layer template that reads the GA-4 export package directly, plus in-DAW tooling that makes game-music exports right the first time (loop-seam audition, platform loudness conformance, batch stem variants). No new DAW features beyond game-music export quality; no middleware bridge (Godot path is raw files). Each track ships a `docs/notes/s-*.md` teaching-first primer.

## Success Criteria

- A Godot 4 demo project in `godot-template/` loads a real GA-4 export package (stems + bank JSON), switches explore/combat layers on a test state toggle, and loops seamlessly — five-minute setup from the runbook.
- Loop-seam audition in-DAW: any cue loops gaplessly in the simulator before export; the validator rejects packages whose loop boundaries click above threshold.
- One-click platform conformance: loudness/true-peak presets per target (PC + console specs), conform + report; batch variants export all layer mixes in one pass.
- `bun run check` green throughout; contracts additive-only; full gate (`cargo test`, `bun run test`, `test:e2e`, vite build) green at the end.

## Key Decisions

1. **Godot template first.** It turns the 30-minute import runbook into a 5-minute job and answers v3 Open Questions 2–3 with real evidence.
2. **Catch loops before export, not after.** Seam audition + validator threshold in-DAW; the game never debugs a click again.
3. **Conform, don't just measure.** Q-6 measures; v4 presets + one-click conform + report per platform target.
4. **Batch the boring part.** All layer/state mixes export in one pass with one manifest.
